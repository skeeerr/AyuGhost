# AyuGhost

**Переработанная реализация и дальнейшая разработка.**

Плагин для exteraGram: режим призрака, архив сообщений, история правок,
фильтры и инструменты локального управления чатами.

**Изменённая версия от 14.11.2026. Лицензия: GPL-3.0-only.**

## Статус

В этом репозитории опубликован **AyuGhost · Source Test 1.0**: неполный
тестовый Python-перенос без DEX и собственного загрузчика исполняемого кода.
Это не подтверждённая замена предыдущей сборки и не заявление о полной
проверке безопасности или прохождении модерации.

20 проверок на компьютере прошли. Запуск и все сценарии на Android
не проверены. Полный перечень различий: [KNOWN_LIMITATIONS.md](KNOWN_LIMITATIONS.md).

## Скачать и проверить

[Скачать ayughost_source_test.elyx](ayughost_source_test.elyx?raw=true)

Нужны exteraGram 13.1.1+ и поддержка Elyx SDK 1.4.5.3+.
Отправьте файл в Избранное, откройте в exteraGram и сначала изучите отчёт
проверки. Перед включением тестовой версии выключите другую версию AyuGhost.

Тестовая сборка имеет отдельный ID `ayughost_source_test` и не заменяет
рабочий плагин. При первом запуске локальная база копируется через SQLite
backup в `ayughost_source_test.db`. Старый файл `ayughost.db` остаётся на месте.
При очистке тестового архива удаляется только копия.

## Что реализовано

- Основные правила скрытия онлайна, набора, прочтений и просмотров историй.
- Исключения по ID чата.
- Локальное сохранение полученных удалённых сообщений и снимков правок.
- Метки и приглушение удалённых сообщений.
- Настройки локального исчезновения одноразовых медиа.
- Регулярные фильтры, локальное скрытие пользователей и диалогов.
- Основные настройки отправки, локального Premium и скриншотов.
- Диагностика регистрации перехватов и меню действий.

**Ещё не перенесены полностью:** копирование защищённых медиа через
re:forward, подстановка доступных Premium-эмодзи, реальный собственный
last seen и часть оформления цитат и нативного архива.

## Проверка и сборка

Достаточно Python 3.10+. Сборка использует только стандартную библиотеку:

```bash
python3 -m unittest discover -p 'test_source_port.py' -v
python3 build.py
```

Результат: `ayughost_source_test.elyx` в корне репозитория.
Это ZIP-совместимый Elyx-архив с `refmap.json`, `metainfo.json` и исходниками.
Python-байткод, DEX, JAR и нативные библиотеки в пакет не включаются.

## Исходники и разрешения

`main.py` содержит настройки и меню; `native.py` — перехваты штатных классов
клиента; `policy.py` — правила приватности; `storage.py` — локальный архив.
Исходники распространяются вместе с устанавливаемым файлом.

Работа с сообщениями, локальной базой и штатными запросами Telegram нужна
для заявленных функций. Такие предупреждения сканера могут оставаться.
Скриншот отдельного отчёта не подтверждает безопасность всех сценариев.
