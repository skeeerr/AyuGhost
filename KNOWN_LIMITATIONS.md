# Source Test: статус переноса

Это отдельная тестовая сборка, а не подтверждённая замена рабочей AyuGhost.
ID: ayughost_source_test. Имя: AyuGhost · Source Test. Версия: 1.0.

Из пакета полностью исключены DEX, бинарные библиотеки и самостоятельная загрузка исполняемого кода. Исходники доступны в архиве. Загружаются только штатные классы клиента через API SDK.

Перенесены: сетевые правила призрака и исключения, локальное сохранение удалённых, снимки и история правок, метки и прозрачность удалённых, отключение локального исчезновения медиа, фильтры и локальное скрытие пользователей, основные параметры отправки, локальный Premium, FLAG_SECURE, меню и три страницы настроек.

Не подтверждено на Android:
- точные сигнатуры методов конкретной версии клиента и преобразования Python/Java;
- сохранение всех типов медиа, правок и историй в реальных чатах;
- перерисовка меток сообщений и уведомления;
- отображение нового отчёта сканера.

Функции, которые НЕ перенесены полностью:
- копирование защищённых фото/видео/документов через re:forward; перенесено только снятие локальных ограничений меню;
- подстановка доступных эмодзи при исходящих сообщениях с локальным Premium;
- показ реального собственного last seen в профиле;
- оформление сворачиваемых цитат и полное воспроизведение прежнего нативного архива/редактора;
- редактор исключений в чате заменён на страницу настроек по ID.

Поэтому паритет с предыдущим плагином не заявляется. Рабочий пакет и опубликованный сайт не заменены. Для тестирования необходимо выключить рабочую версию, чтобы перехваты не конфликтовали.

Исходная база ayughost.db копируется через SQLite backup в ayughost_source_test.db один раз. Тестовая версия работает только с копией. Исходные настройки читаются при первом запуске и копируются в настройки отдельного тестового ID. При очистке архива удаляется только тестовая копия.

Предупреждения о перехватах, файлах и доступе к сообщениям ожидаемы. Отсутствие Remote code требует проверки самим клиентом, гарантии прохождения модерации нет.
